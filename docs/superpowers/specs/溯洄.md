# 溯洄

> 状态：设计稿 · 2026-11-15
> 名字取自《诗经·蒹葭》「溯洄从之」：逆流而上，去找源头。开场一句：**光阴者，百代之过客。**（李白）

## 1. 是什么

时空地层里的一段动画：从「今」开始，一层一层往下沉，直到新石器。上一层退成虚影，下一层浮现；镜头跟着都城走；你的博物馆是贯穿每一层的锚点——同一个位置，不同的时代。每过一层，响起那个朝代的乐器。

## 2. 体验

| 部分 | 设计 |
|---|---|
| 入口 | 时空视图里，「奏一曲」旁边一个按钮「溯洄」 |
| 开场 | 镜头停在「今」，你的馆印微微亮起；字幕「光阴者，百代之过客」 |
| 每一层 | 镜头沉到这一层，并移向这一层的都城（`DYNASTY_GEO` 的 trail，迁都时沿 trail 移动）；上一层淡成虚影，更下面的层几乎看不见；这一层的疆域、都城亮起 |
| 锚点 | 你打过卡的馆，琴弦（竖线）始终可见；经过它关联的层时，那个点亮一下 |
| 字幕 | 朝代名 + 年代 + 一句话；如果这一层有你去过的馆：「你在陕西历史博物馆见过这一层」 |
| 声音 | 进入每层时奏这个朝代的乐器（`ERA` 音色）一个短句；有名曲的朝代奏名曲的一句（`TUNES`）。静音开关沿用现有的 |
| 节奏 | 不平均：大朝代（秦汉、唐、宋、明清）停留久一些，短的过得快；全程约 75 秒 |
| 结尾 | 停在新石器的满天星斗；字幕「百代过客，你走过其中 N 层」（没打卡：「这是你的第一层」之类），按钮「再溯一次」「回到今天」 |
| 控制 | 暂停 / 继续、跳到下一层、退出（Esc 或关闭）；点左侧标尺上的某一层，从那一层接着溯 |
| 降低动态 | 系统开启「减少动态效果」时，不飞镜头，只做层与层之间的淡入淡出 |

## 3. 不做（以后）

- 古 → 今的「上溯」版本，作为「一脉相承」成就的奖励。
- 导出视频分享。
- 每层展示镇馆之宝图片（地层视图里还没有文物数据）。

## 4. 实现要点

- 全部在 `src/ui/client/strata.ts` 内完成：复用 `applyFocus` 的镜头取景、层的透明度动画、`buildFocusPath`/都城 trail、`stringSound` 与 `ERA`/`TUNES`。
- 一条时间线：`[{ layer, dwell, from, to }]`，按 `requestAnimationFrame` 推进；声音用音频时钟排程。
- 与「奏一曲」互斥：开始溯洄会停掉正在演奏的曲子，反之亦然。
- 进行中屏蔽地层点击、拨弦；任何拖动视为暂停。
