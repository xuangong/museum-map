# 寄 —— 分享重做

> 状态：设计稿 · 2026-11-15
> 取「寄」：古人把东西托给远方的友人，叫寄。陆凯「折花逢驿使，寄与陇头人」。
> 原则：**文艺气息为主**。分享出去的是一卷有叙述感的东西，不是一张数据海报，也不是一个 App 链接。

## 1. 为什么重做

旧的「分享海报」（`/u/:handle/share`，AI 写文案 + 5 种 SVG 版式）已经坏了，也装不下现在的内容：成就、历史的音符（奏一曲）、溯洄。
主要渠道是**微信好友 / 群**——发出去的是一个链接，对方点开是一页可以听、可以看、可以读的东西。

## 2. 载体：手卷

每一次「寄」都生成一卷手卷。手卷本身就是古人分享与观看的完整形制，按它的结构来：

| 部分 | 内容 |
|---|---|
| **签条** | 卷名，如「溯洄图卷」「汉唐宋三代合奏」「丝路行纪」 |
| **引首** | 四个大字（策展好的固定词库，不由 AI 生成） |
| **画心** | 寄出的那一刻在这里重演，旁边配叙述 |
| **题跋** | 寄卷人的跋：干支年 + 节气 + 一句古雅的记述；可再附一句自己的话 |
| **鉴藏印** | 寄卷人打过卡的馆，作为印章钤在卷边 |
| **观款** | 收到的人可以钤一方「观」：「某某 观」 |
| **卷尾** | 「展开你自己的一卷」 |

页面竖向展开（手机上往下滑就是展卷），宣纸底、朱砂印、衬线字，留白宽。

## 3. 四种卷

| 卷 | 入口（按钮文字） | 签条 | 引首 | 画心 |
|---|---|---|---|---|
| **曲** | 奏一曲结束后「寄此曲」 | 「汉唐宋三代合奏」（≤4 个朝代列名，否则「十七代合奏」） | 从「遗音」词库按 seed 取：百代遗音 / 金石之声 / 丝竹余韵 / 弦上千年 | 时空地层重奏同一曲（同 seed、同打卡集合）；奏到某个朝代时，旁注这一层的乐器；有名曲的，写名曲名 + 故事 + 「今所奏出自明《神奇秘谱》」；只存歌词的，如实写「曲调已失传」 |
| **行** | 溯洄结尾卡「寄此行」 | 「溯洄图卷」 | 溯洄从之 | 重演溯洄；每层旁注：这一朝的一件大事、一条文化、都城，以及「TA 在 陕西历史博物馆 见过这一层」；以「百代过客」收束 |
| **印** | 落印仪式「寄此印」 | 成就名 | 每个成就一个四字引首（成就数据新增字段，手写 35 个） | 印章钤下的动画，成就展签全文，解锁它的馆列为「所见」 |
| **长卷** | 侧栏 / 个人页「寄一卷」 | 「某某的长卷」 | 平生所见 | 寄卷人的整个地层（只读），所有已得成就的印 |

博物馆 / 朝代抽屉里的分享按钮保留现在的行为（复制站内链接），只改文字：图标按钮，提示「寄给友人」。

### 叙述的来源

全部来自已经核对过的数据，不让 AI 现编：
- 朝代：`data/dynasties/*.yaml` 的 `events`、`culture`、都城（`DYNASTY_GEO`）
- 名曲：`src/data/era-tunes.ts` 的 `name / story / from`
- 成就：`src/data/achievements.ts` + `src/data/achievement-labels.ts`
- 乐器：`strata.ts` 的 `ERA` 音色名

## 4. 题跋

由模板拼成，数字用汉字，年份用干支，节气取寄卷当时的（`solar-term.ts` 已有 `chineseYear`、`currentSolarTerm`）。

| 卷 | 模板 | 例 |
|---|---|---|
| 曲 | {干支}年{节气}，{名}以{N}馆之印，奏{朝代}之音。 | 乙巳年立冬，小明以十四馆之印，奏汉、唐、宋三代之音。 |
| 行 | {干支}年{节气}，{名}溯洄而上，自今及于新石器，所过{N}层。 | 乙巳年立冬，小明溯洄而上，自今及于新石器，所过二十层。 |
| 印 | {干支}年{节气}，{名}集{馆}之印，得「{成就}」。 | 乙巳年立冬，小明集殷墟、二里头、郑州之印，得「三代」。 |
| 长卷 | {干支}年{节气}，{名}集{N}馆之印，叠为{M}层。 | 乙巳年立冬，小明集十四馆之印，叠为二十层。 |

（例子里的干支、节气只是示意，实际值以 `chineseYear`、`currentSolarTerm` 的输出为准。）

馆名多于三个时写「殷墟、二里头等五馆」。
寄卷人的署名：登录用户默认用 display name，可改；匿名用户寄卷时可填，不填就是「无名氏」。自己的一句话可选，≤40 字。

签条下方的小字随节气所在的季节变：

| 季 | 句 | 出处 |
|---|---|---|
| 春 | 江南无所有，聊赠一枝春 | 陆凯《赠范晔》 |
| 夏 | 感此怀故人，中宵劳梦想 | 孟浩然《夏日南亭怀辛大》 |
| 秋 | 海上生明月，天涯共此时 | 张九龄《望月怀远》 |
| 冬 | 晚来天欲雪，能饮一杯无 | 白居易《问刘十九》 |

## 5. 收到的人

- 打开：首屏是签条、引首、季节小字，一个「展卷」按钮（微信不允许自动出声，需要一次点击）。
- 画心播完，往下是题跋、鉴藏印、观款、卷尾。
- **观款**：钤一方「观」，可填名字（2–8 字，过滤敏感词）；不填就是「某君 观」。每台设备每卷只能钤一次；按 IP 限流。卷上显示最近 30 方观款和总数。
- **同游**：如果对方自己也在本站打过卡（本地或账号里的足迹），在观款下面轻轻一行：「你与 TA 同游 唐·宋·明」。没有就不显示。
- **卷尾**：「展开你自己的一卷」→ 首页。

## 7. 实现要点

### 数据
迁移 `0016_share_scrolls.sql`（只新增表，不动已有数据）：

```sql
CREATE TABLE share_scrolls (
  id TEXT PRIMARY KEY,          -- 8 位短 id
  kind TEXT NOT NULL,           -- 'tune' | 'voyage' | 'seal' | 'scroll'
  payload TEXT NOT NULL,        -- JSON 快照
  user_id TEXT,                 -- 登录用户；匿名为 NULL
  created_at INTEGER NOT NULL
);
CREATE TABLE share_guan (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  scroll_id TEXT NOT NULL REFERENCES share_scrolls(id) ON DELETE CASCADE,
  name TEXT,
  created_at INTEGER NOT NULL
);
CREATE INDEX idx_share_guan_scroll ON share_guan(scroll_id, created_at);
```

payload 冻结寄卷那一刻：`{ name, line, visitedIds, ganzhi, term, seed?, era?, achId? }`。之后足迹变了，卷不变。

### 路由
- `POST /api/scrolls` —— 封卷，返回 `{ id }`；按 IP 限流（`RATE` KV）。
- `GET /s/:id` —— 服务端渲染手卷页：网页标题、description（= 题跋）、og 标签；叙述文字在服务端拼好放进页面。
- `GET /api/s/:id/guan`、`POST /api/s/:id/guan` —— 观款列表 / 钤印。
- `GET /u/:handle/share` —— 301 到个人页（旧链接不 404）。

### 前端
- 纯逻辑 `src/ui/client/scroll-core.ts`（同 `TripCore`、`AchCore` 的模式，测试里用 `new Function` 执行）：数字转汉字、干支 + 节气题跋模板、签条、引首取词、季节句、同游计算。
- 手卷页复用 `/assets/strata.js`：`MuseumStrata.init` 以只读方式挂载（点馆不开抽屉），用快照里的 `visitedIds` 调 `update`。
- `MuseumStrata` 新增：
  - `play({ seed, era })`：按给定 seed 重奏；
  - `voyage()`：开始溯洄；
  - 回调 `onTuneEra(li)`、`onVoyageLayer(li)`、`onEnd()`，手卷页据此逐条亮出旁注。
- 设备不支持 WebGL 时：画心只显示叙述文字，写「此处画心，需在支持 3D 的设备上展开」。
- 「封卷」面板：署名、自己的一句话（可选），确定后复制链接 → 「卷已封好，寄去吧」；系统浏览器里支持 `navigator.share` 的直接调系统分享。

### 移除
`src/routes/share.ts`、`src/ui/share-poster.ts`、`src/ui/poster-atoms.ts`、`src/services/share-poet.ts` 及其测试；个人页「分享海报」改「寄一卷」。
